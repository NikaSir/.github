# Specialized Panel UI Standard — compatibility pointer

This filename is retained for existing repository links only.

The sole current authority is [`NIKAS_SPECIALIZED_PANEL_UI_STANDARD.md`](NIKAS_SPECIALIZED_PANEL_UI_STANDARD.md), version 1.8, together with its required [navigation contract](docs/NIKAS_PANEL_NAVIGATION_CONTRACT.md). It replaces every earlier rule for Header navigation, Back, safe areas, zoom, scrolling, panning, rendering, typography, connection/freshness indicators, Bottom Tab Bar geometry and repository/integration icons.

Implementations must not combine historical rules with v1.8. In particular, the permanent left Header action is the Home Assistant system menu, the exact LIDER center plaque is the sole return control, and GitHub Releases and automatic release tags are not part of the NikaS panel publication workflow.
