# Support

Use the affected repository's issue tracker for reproducible defects, compatibility problems, installation failures, and feature requests.

Before opening an issue:

1. Check the repository README and documentation.
2. Search existing open and closed issues.
3. Confirm the problem on the latest supported release when practical.
4. Remove secrets and personal data from logs and screenshots.

A useful support report includes:

- repository and version;
- platform and relevant software versions;
- hardware or device model when applicable;
- expected behavior;
- actual behavior;
- exact reproduction steps;
- sanitized logs or diagnostics;
- whether the problem is persistent or intermittent.

Do not use public support channels to disclose security vulnerabilities. Follow `SECURITY.md` instead.
